# v1.1.1 Ajustes y fichas de ejercicio — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Exercise detail cards (API + app info screen) and post-test adjustments (title, voice countdown, block separation).

**Architecture:** Exercise cards are optional fields on the shared exercise catalog, loaded by an artisan command from JSON and synced to the app like the rest of the catalog. The player's info button pauses and opens a full-screen card.

**Spec:** `~/Projects/workout-design/2026-11-10-v1.1-plan-y-rediseno.md` (section "v1.1.1" and Dudas resueltas 5-7).

## Global Constraints
- Same as `plans/2026-11-10-v1.1-plan-y-rediseno.md` Global Constraints (branches `develop`, commit trailer, test/lint commands, import/order caveat, no whole-repo prettier, no worktrees, Spanish UI).
- Exercise card fields: `description` (string|null), `steps` (string[]), `muscles` (string[]), `tips` (string[]). Empty arrays/null when unknown.

## Review Focus
1. Exercises without card data: info screen shows name + "Aún no hay descripción para este ejercicio", never crashes.
2. Opening the info screen pauses; closing leaves the run paused (no auto-resume); the timer does not advance while it is open.
3. Countdown voice only on: last 3 s of work steps and last 3 s of main-block between-exercise rests (rest steps in a `main` block that are not `switchSide` and not between sets of the same exercise). No countdown beeps at all.
4. Old Dexie exercise rows without the new fields keep working.
